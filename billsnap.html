BillSnap Pro

Smart Bill & Receipt to PDF Management Tool

Project Overview

BillSnap Pro is a client-side document processing tool engineered to solve the friction of organizing multiple scattered receipt photos into clean, consolidated PDF expense records.

Traditional mobile scanner tools often impose paywalls, require cloud uploads of sensitive financial receipts, or produce massive uncompressed files. BillSnap Pro addresses this by processing images directly in the browser, compiling them into a lightweight document under 2MB.

The Problem

Students, freelancers, and small business owners frequently accumulate dozens of physical receipts. Manually uploading multi-megabyte photos for expense claims creates file size rejection errors, slow transfers, and unorganized record management.

What I Built

Client-Side Image Optimization: High-resolution photos are pre-processed and compressed in the browser before bundling, maintaining clarity while staying under strict file size thresholds.
Structured PDF Compilation: Automatically organizes and formats multiple receipt captures into clean page layouts suitable for official submissions.
User Authentication & Dashboard: Intuitive portal layout allowing users to track previous batches and manage expense categories.
Zero Cloud Leakage: Processing receipts on the client ensures personal expense data never leaves the user's browser without explicit export.
